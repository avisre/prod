# Policy change 2026-09-11: default flipped from allow-all to deny-all. Render's
# Hobby-plan bandwidth (5GB/mo) was being consumed primarily by bot/crawler
# traffic hitting the SEO page surface — 68% of all site traffic was bots, and
# Meta's AI crawler alone was 53% of ALL traffic. backend/bot-blocker.js
# enforces this same policy server-side (403), since robots.txt is only a
# request a crawler can choose to ignore. The two files must agree
# agent-by-agent — drift is caught by backend/test/robots-policy.test.js. Full
# rationale in docs/growth/bot-crawler-situation-2026-09-05.md.
#
# Policy amendment 2026-09-24: the crawlable set is no longer Google + Bing
# only. OAI-SearchBot and PerplexityBot were moved out of the refused group
# into the Allowed — AI answer-engine INDEX crawlers section below, because they
# populate answer-engine indexes rather than training corpora and refusing them
# closed a citation channel. They are IP-verified against the ranges their
# vendors publish and, unlike Google and Bing, are NOT exempt from the nav rate
# limit — that limit is the bound they were admitted under. Every training-only
# crawler (GPTBot, CCBot, Bytespider, ClaudeBot, meta-externalagent) remains
# refused.
#
# Denied here does not mean unavailable. Licensed bulk data (SEC as-filed
# fundamentals plus filing-change deltas, every row carrying a sourceUrl back
# to EDGAR) and MCP/API access for agent builders are offered at
# https://stockportfolio.pro/licensing. That page, /llms.txt and this file stay
# fetchable for every agent, allowed or denied.
#
# /login and /news carry <meta robots noindex> and are deliberately left
# crawlable for Google/Bing below so the noindex itself can be read and
# honored (blocking them here caused a "blocked by robots.txt" Search
# Console warning instead of a clean drop). /register stays crawlable too —
# it's a conversion landing page.

# Google-Extended is NOT a crawler and NOT a separate agent — per Google,
# "Google-Extended doesn't have a separate HTTP request user agent string";
# the token is "used in a control capacity". It governs whether content
# Googlebot already crawled may be used to train future Gemini models and to
# ground them. No request ever arrives carrying this user agent, so this
# stanza changes nothing about fetching: Googlebot (allowed above) does all
# the fetching, and this line decides only what that content may then be used
# for. Google states it plainly: "Google-Extended does not impact a site's
# inclusion in Google Search nor is it used as a ranking signal in Google
# Search." Kept as its own stanza (rather than folded into the wildcard) so a
# future "let's allow Google" edit cannot silently re-admit Gemini training.
User-agent: Google-Extended
Disallow: /

# Allowed — AI answer-engine INDEX crawlers (not training crawlers)
# ---------------------------------------------------------------------------
# These two are admitted on a different argument from the refused group below.
# They populate answer-engine indexes: OAI-SearchBot's own documentation states
# that an opted-out site "won't appear in ChatGPT search answers." Refusing
# them therefore closes a citation channel rather than saving bandwidth, which
# is what the 2026-09-11 deny-by-default rewrite was actually for.
#
# They are not simply re-allowed. backend/bot-blocker.js verifies each against
# the IP ranges its vendor publishes — https://openai.com/searchbot.json and
# https://perplexity.com/perplexitybot.json — because neither vendor publishes
# a reverse-DNS hostname, so the PTR method used for Google and Bing cannot
# apply to them. Unlike Google and Bing they are also deliberately NOT exempt
# from the per-IP navigation rate limit: verification stops an impostor taking
# their name, and the rate limit is what bounds their crawl on a 5GB plan.
#
# The training-only crawlers (GPTBot, CCBot, Bytespider, ClaudeBot) remain
# refused below. That is a separate call and this section does not revisit it.
User-agent: OAI-SearchBot

Disallow: /api/

Disallow: /dashboard.html
Disallow: /fundamentals

Disallow: /v1/
