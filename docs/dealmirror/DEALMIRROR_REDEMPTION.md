# Redemption instructions

1. Create or sign in to the one StockPortfolio.pro account that will hold the licence.
2. Open `/dealmirror/redeem` and enter the DealMirror code.
3. A code is permanently bound to the first eligible account that redeems it.
4. Accounts with AppSumo lifetime access or an active paid Stripe subscription must contact support for a manual review; redemption never downgrades existing access.
5. Codes remain redeemable while sales are active, then until sales-end plus 60 days. Unredeemed expired/refunded/revoked codes cannot be reused.
