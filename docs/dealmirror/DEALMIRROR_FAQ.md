# DealMirror FAQ

**Is AI unlimited?** No. Starter/Investor/Pro include 30/100/300 Ask questions per month.

**Can I stack codes or share an account?** No. One DealMirror licence is for one named user and account.

**Can I use it with clients or through an API?** No. This pilot is for personal investment research, has no API and excludes client-facing commercial use.

**What happens after a refund?** The associated DealMirror entitlement is revoked without affecting a separate legitimate AppSumo, Stripe, Power or Desk entitlement.

**Does this include Power or Desk?** No. Those are separate recurring website plans.
