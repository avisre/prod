# Microsoft 365 Copilot agent

A declarative agent whose one action is our remote MCP server (`/mcp/apps`). Built 2026-10-09; not yet
provisioned in any tenant and not submitted.

## What is here

- `appPackage/manifest.json`, `declarativeAgent.json`, `ai-plugin.json`: generated by
  `node scripts/build-copilot-package.js` from the server's own tool list. Do not edit by hand; rerun the script
  when a tool in `backend/mcp-apps.js` changes (`--check` fails when they are stale, and
  `backend/test/copilot-package.test.js` runs that).
- `appPackage/color.png` (192x192) and `outline.png` (32x32, white on transparent): made from the 512px listing
  logo (`~/appsumo-listing-images/logo.png`, not in the repo).

All three JSON files validate against Microsoft's published schemas (Teams manifest 1.22, declarative agent 1.6,
plugin 2.4). No description contains a URL or an emoji, which the store validation requires.

## Sign-in

Microsoft's token store registers itself with our server (dynamic client registration) and requires the server
to issue a client secret. `backend/oauth-mcp.js` does that since 2026-10-09 for any client that asks for
`client_secret_post` or `client_secret_basic`, and for any registration returning to `teams.microsoft.com`.
**That change has to be deployed before the steps below can work.**

## Steps that need a Microsoft account (owner)

1. A Microsoft 365 work tenant with a Copilot licence and custom app upload enabled.
2. VS Code with Microsoft 365 Agents Toolkit 6.12 or later. Open this folder, sign in under Accounts.
3. Add the action's sign-in: authentication type **OAuth (with dynamic registration)**, server URL
   `https://www.stockportfolio.pro/mcp/apps`. The toolkit registers a client with us, creates the auth config and
   gives its id; put that id in the env file as `STOCKPORTFOLIO_MCP_AUTH_ID` (the placeholder in
   `ai-plugin.json`).
4. Lifecycle, Provision. Open m365.cloud.microsoft/chat, pick the agent, ask for a company's revenue, sign in with a
   StockPortfolio.pro account when prompted.
5. For the public store: enrol in the Microsoft 365 and Copilot program in Partner Center (business verification
   takes a few days), then submit the zipped `appPackage`. Reviews reportedly take four to six weeks and often
   more than one round. The reviewer needs a test account with a plan that includes the connector.

## Not verified
